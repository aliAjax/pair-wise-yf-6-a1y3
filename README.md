# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

## 保险理赔批次

- **入批条件**：已投保、状态已完成、费用大于零、有照片链接，四项同时满足才可勾选入批；旧数据中的事项按未投保处理，新登记事项默认投保。
- **提交**：勾选事项后生成批次（状态待审核），所选事项立即锁定；任一事项存在未结理赔（待审核批次中仍锁定）时整批拒绝，原批次不做任何改动。
- **锁定期间**：费用、照片或状态被改动时自动撤回该事项（批次和事项历史均保留）；全部撤回后批次关闭。备注、优先级改动不影响锁定，锁定期间禁止删除。
- **审核通过**：逐项登记赔付额，任一赔付额高于该事项费用（或为无效金额）则整批拒绝并释放全部锁定事项；通过后事项标记已赔付并防止重复理赔。
- **驳回**：批次驳回，事项释放，可重新入批。
- **同步**：维修列表、费用/赔付统计与 localStorage 存档随每次操作同步；刷新页面数据保留。

代码按职责拆分为三个业务文件：

| 文件 | 职责 |
| --- | --- |
| `src/claims.js` | 理赔判定：入批资格、未结冲突、建批、自动撤回、审核规则（纯函数） |
| `src/store.js` | 状态存储：localStorage 存档与旧数据迁移、事项/批次变更、统计 |
| `src/ui.js` | 页面交互：渲染、事件委托、表单与审核操作 |

`npm test` 运行理赔规则与存储层的断言脚本（无需第三方依赖）。
