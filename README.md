# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

## 保险理赔批次（第二版）

业务拆分为三个文件：

- `src/claims.js`：理赔判定（入批条件、未结冲突、撤回与审核规则，纯函数）
- `src/storage.js`：状态存储（localStorage 读写，旧数据迁移）
- `src/ui.js`：页面交互（渲染、编辑、批次提交与审核）

规则：

1. 仅「已投保、已完成、费用大于零、有照片链接」的事项可入批。
2. 提交时任一事项存在未结理赔（待审核且锁定中）则整批拒绝，不创建批次，原批次不动。
3. 提交成功后批次进入待审核，所选事项锁定；锁定中不可删除。
4. 事项在待审核批次期间改动费用、照片或状态，自动从批次撤回，批次与快照作为历史保留。
5. 审核通过需登记赔付额，赔付额高于在批事项费用则整批拒绝；驳回或超赔拒绝均释放事项。
6. 事项列表、费用统计与理赔批次同步；旧版本事项按「未投保」迁移，刷新后保留。
